The project

The drama remains. The format changes.

Novelas Clásicas turns universal literary conflicts into 45–65 second episodes designed for the vertical screen.

Each series combines narrative adaptation, multi-character vocal performance, visual continuity, subtitles and editing. AI accelerates parts of the process; it does not replace editorial decisions or final review.

Creative workflow

From page to episode, with review before publishing.

A structured flow preserves creative intent and creator control at every stage.

  1. Adaptation

    Select a public-domain work, choose a creative route and write the episodic arc.

  2. Vertical video production

    Multi-character narration, 9:16 visuals, selective motion, subtitles and editing.

  3. Pre-publication review

    The creator reviews the video, metadata, visibility and privacy settings before authorizing any action.

  4. Authorized TikTok publishing

    The planned local tool will send a draft or publish only after explicit confirmation, through the official API and an authorized account. This integration is still in development.

Planned integration

Publishing with consent, not engagement automation.

Noveleando’s local tool is being developed so the creator can manage publishing of their own content to their own TikTok account through OAuth 2.0 and the official Content Posting API. It is not a public account service, spam bot, or tool for automating likes, comments or followers.

The intended scopes for review are:

  • user.info.basic
  • video.upload
  • video.publish

Current status: registration, permissions and the publishing flow are in progress. This site does not claim the integration is operational or guarantee TikTok approval.

The static callback displays the authorization response for completion in the local tool. It does not store codes, exchange tokens or contain secrets.
