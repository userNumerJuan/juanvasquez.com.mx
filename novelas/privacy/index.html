Privacy Policy

Controller: Juan Vasquez / Noveleando, Sonora, Mexico. This policy applies to the Novelas Clásicas microsite, its static OAuth callback, and the local creator tool under development.

1. Current status

The TikTok integration is not operational. No public account service is offered. At this stage, the website and static callback do not collect TikTok profile information, OAuth tokens, videos, or publishing logs. The intended future behavior is described separately below and will be updated before activation.

2. Website data

  • No user registration, contact form, advertising, third-party analytics, or tracking cookies are used.
  • The language preference is stored only in your browser’s localStorage under nv-language. Clearing this site’s browser data removes it.
  • If you choose to email us, your provider processes the address, message and delivery metadata. We use that information only to respond to your inquiry or deletion request.

3. Intended TikTok OAuth scopes and data

When the integration is implemented and authorized, the local tool will request only the scopes needed for the creator’s selected action:

  • user.info.basic: access to limited basic profile information, such as open_id and creator display name when returned by TikTok, to identify the authorized account.
  • video.upload: to send a creator-selected video as a draft after explicit confirmation.
  • video.publish: to publish a creator-selected video only after review of its metadata and privacy settings and explicit confirmation.

The local flow may process the selected video file, caption or title, visibility and privacy metadata, the authorization response, and tokens needed to execute the requested action. The static website does not receive those videos or tokens.

4. Authorization codes and tokens

The static callback reads code, state, error and error_description from the URL and displays them only in the current browser tab. It does not use localStorage, transmit parameters to third parties, include a client_secret, or exchange codes for tokens. The code-to-token exchange must occur in the creator’s local tool or a secure backend, never in this public page.

Tokens must be used only to execute actions requested by the creator. The local tool’s exact token-storage and retention behavior has not yet been finalized; no unimplemented security or retention promise is made here. This section will be replaced with verified behavior before activation.

5. Sharing and sale of data

We do not sell or share TikTok user data with third parties. When the local integration becomes operational, data will be transmitted to TikTok’s official API only as necessary for an action initiated and authorized by the creator. This website has no advertising or analytics recipients.

6. Retention and deletion

Because the integration is not operational, Noveleando currently retains no TikTok profile data, tokens, video files, or publishing logs. The callback retains no authorization code after the tab is closed and replaces the address-bar URL after capturing it for display. Browser behavior outside the site’s control may still retain visited-page information until the user clears browser history.

You can clear the site’s language preference through your browser, revoke Noveleando’s access from your TikTok account’s app permissions or connected-apps settings, and request deletion of email correspondence through the contact below. Instructions are also available on the data deletion page.

7. Changes and contact

Material changes will be posted at this URL with an updated effective date. Before any integration is enabled, this policy will be reviewed so it matches actual scopes, storage, retention and deletion behavior. For privacy questions or deletion requests, use the contact button below.

Política de privacidad

Responsable: Juan Vasquez / Noveleando, Sonora, México. Esta política aplica al micrositio de Novelas Clásicas, su callback OAuth estático y la herramienta local del creador en desarrollo.

1. Estado actual

La integración con TikTok no está operativa. No se ofrece un servicio público de cuentas. En esta etapa, el sitio y el callback estático no recopilan información de perfil de TikTok, tokens OAuth, videos ni registros de publicación. El comportamiento futuro previsto se describe por separado y se actualizará antes de su activación.

2. Datos del sitio web

  • No se utilizan registros de usuario, formularios de contacto, publicidad, analítica de terceros ni cookies de seguimiento.
  • La preferencia de idioma se guarda únicamente en localStorage de tu navegador bajo nv-language. Se elimina al borrar los datos de este sitio en el navegador.
  • Si decides escribir por correo, tu proveedor procesará la dirección, el mensaje y los metadatos de entrega. Usaremos esa información solo para responder a tu consulta o solicitud de eliminación.

3. Alcances OAuth de TikTok y datos previstos

Cuando la integración esté implementada y autorizada, la herramienta local solicitará solo los alcances necesarios para la acción elegida por el creador:

  • user.info.basic: acceso limitado al perfil básico, como open_id y nombre de creador cuando TikTok lo devuelva, para identificar la cuenta autorizada.
  • video.upload: para enviar como borrador un video seleccionado por el creador después de una confirmación explícita.
  • video.publish: para publicar un video seleccionado únicamente después de revisar metadatos y privacidad, y contar con confirmación explícita.

El flujo local podrá procesar el video seleccionado, descripción o título, visibilidad, metadatos de privacidad, respuesta de autorización y tokens necesarios para ejecutar la acción solicitada. El sitio estático no recibe esos videos ni tokens.

4. Códigos de autorización y tokens

El callback estático lee code, state, error y error_description de la URL y los muestra únicamente en la pestaña actual. No utiliza localStorage, no transmite parámetros a terceros, no incluye client_secret ni intercambia códigos por tokens. El intercambio deberá ocurrir en la herramienta local del creador o en un backend seguro, nunca en esta página pública.

Los tokens deberán utilizarse solo para ejecutar acciones solicitadas por el creador. El almacenamiento y retención exactos de tokens en la herramienta local todavía no se han definido; aquí no se prometen medidas aún no implementadas. Esta sección se sustituirá por el comportamiento verificado antes de la activación.

5. Venta y compartición de datos

No vendemos ni compartimos datos de usuarios de TikTok con terceros. Cuando la integración local esté operativa, los datos se transmitirán a la API oficial de TikTok únicamente cuando sea necesario para una acción iniciada y autorizada por el creador. Este sitio no tiene destinatarios de publicidad o analítica.

6. Conservación y eliminación

Debido a que la integración no está operativa, Noveleando actualmente no conserva perfiles de TikTok, tokens, videos ni registros de publicación. El callback no conserva el código después de cerrar la pestaña y reemplaza la URL de la barra de direcciones después de capturarla para mostrarla. El navegador puede conservar información de páginas visitadas fuera del control del sitio hasta que el usuario borre su historial.

Puedes borrar la preferencia de idioma desde el navegador, revocar el acceso de Noveleando desde los permisos de aplicaciones o aplicaciones conectadas de tu cuenta de TikTok, y solicitar la eliminación de correspondencia mediante el contacto siguiente. También consulta la página de eliminación de datos.

7. Cambios y contacto

Los cambios relevantes se publicarán en esta URL con una fecha actualizada. Antes de habilitar una integración, esta política se revisará para que coincida con los alcances, almacenamiento, retención y eliminación reales. Para privacidad o eliminación, utiliza el botón de contacto siguiente.
