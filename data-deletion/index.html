Instrucciones para revocar accesos y eliminar información almacenada localmente.

Instrucciones en español

Estado actual: el sitio no ofrece cuentas y la herramienta de publicación está en desarrollo. Actualmente no existe una base de datos pública de usuarios ni tokens almacenados por este sitio.

Preferencias de este sitio

El idioma y el estado del acertijo se guardan solo en tu navegador. Para borrarlos, abre la configuración de datos de sitios de tu navegador, busca este dominio y elimina sus datos locales. No es necesario contactarme.

Google y YouTube

  1. Abre Conexiones de tu cuenta de Google.
  2. Selecciona la aplicación y elige eliminar todas las conexiones.
  3. Revoca también cualquier sesión local desde la propia herramienta cuando esa función esté disponible.

Facebook e Instagram

  1. Abre Apps y sitios web o Integraciones de negocio en tu configuración de Meta.
  2. Selecciona la aplicación y elimínala.
  3. Si una versión local te permitió conectar una página o cuenta, elimina sus credenciales locales utilizando la opción de desconexión incluida en esa versión.

TikTok

  1. Abre TikTok y entra en Configuración y privacidad → Seguridad → Administrar permisos de apps.
  2. Selecciona la aplicación autorizada y retira el acceso.
  3. Elimina la autorización local desde la herramienta cuando la integración correspondiente esté disponible.

Solicitud manual

Si has enviado información por correo o utilizado una versión de prueba y necesitas confirmar el borrado local de credenciales, utiliza el botón de contacto. Incluye el nombre de la aplicación y la plataforma, pero nunca envíes contraseñas, tokens ni códigos OAuth. La solicitud se usará únicamente para atender la eliminación.

Antes de una publicación pública de cualquier integración, esta página deberá actualizarse con las rutas exactas de desconexión y borrado que esa versión realmente implemente.

Instructions in English

Current status: the website offers no accounts and the publishing tool is under development. There is currently no public user database and this site stores no user tokens.

This website’s preferences

Language and puzzle state are stored only in your browser. To remove them, open your browser’s site-data settings, find this domain, and clear its local data. You do not need to contact me.

Google and YouTube

  1. Open your Google Account connections.
  2. Select the application and remove all connections.
  3. When available, also revoke the local session from the tool itself.

Facebook and Instagram

  1. Open Apps and Websites or Business Integrations in your Meta settings.
  2. Select and remove the application.
  3. If a local version connected a page or account, delete its local credentials using that version’s disconnect option.

TikTok

  1. In TikTok, open Settings and privacy → Security → Manage app permissions.
  2. Select the authorized application and remove access.
  3. Remove the local authorization from the tool when the relevant integration is available.

Manual request

If you sent information by email or used a test version and need confirmation that local credentials were deleted, use the contact button below. Include the application and platform name, but never send passwords, tokens, or OAuth codes. Your request will be used only to handle the deletion.

Before any integration is publicly released, this page must be updated with the exact disconnect and deletion paths implemented by that version.
